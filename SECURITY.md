# Security policy

Clauditor is currently a scaffold, not a released service or collector. Do not
report security issues by posting secrets, raw model conversations, API keys,
private logs, or sensitive telemetry to public GitHub issues.

If GitHub private vulnerability reporting is enabled for the repository, use
that mechanism. Otherwise, contact the repository owner using an established
private channel; do not create a public proof-of-concept containing sensitive
material. A formal reporting channel and supported-version policy will be
specified before product release.

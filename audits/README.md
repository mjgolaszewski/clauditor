# Audits and qualification records

This root holds governed audits, drift reviews and operator-requested reports.
Each report records intent, scope, evidence, outcome and remaining work. Reference
retained provider artifacts and their hashes for measurable claims; local output
alone is non-authoritative.

[Standard-v3 readiness](standard-v3-readiness.yml) preserves the initial defects,
canonical promotion, actual-source inventory, provider qualification and scope
limits. Its early AgentBus HTTP 403 observation is historical: enrollment later
succeeded with a fresh approval, policy acknowledgement and delivered announcement.
The current coordination state is recorded in memory and the active phase log.

The [phase log](../phases/phase-01-log.yml) records execution and the requested
construction pause. [The active ledger](../plans/phase-ledger.yml) owns lifecycle;
editorial summaries neither activate construction nor grant release authority.

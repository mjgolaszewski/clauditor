# Specification workspace

The proposed [Clauditor product requirements v1](clauditor/v1/README.md)
contain machine-readable domain contracts, source obligations, 10-dimensional
producer-consumer edges, state transitions, semantic controls and a deterministic
validator/generator. The specification is a **review candidate** and confers no
runtime, BCF evidence, construction, deployment or release authority.

BCF's active root semantic and planning authorities remain in `AGENTS.yml`,
`plans/`, `governance/`, and `schemas/`. Standard profile contract 3.0 is
installed and provider-verified for the implemented qualification slice. The
canonical P01–P09 roadmap adopts delivery intent for all 39 requirements and
45 construction packets; the full product candidate remains unadmitted.
Construction is paused in the active ledger.
See [the Standard-v3 target](BCF_STANDARD_V3_TARGET.md).

Generated Markdown, diagrams and matrices are projections, not an independent
source of requirements. Large generated outputs should stay out of Git.
